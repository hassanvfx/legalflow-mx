Instalar ChatGPT Codex

AI LegalFlow MX necesita Codex para el flujo guiado.

Pasos

  1. Instala o actualiza ChatGPT Codex para tu sistema.
  2. Abre Codex una vez y confirma que puede abrir un repositorio local.
  3. Vuelve a la terminal y ejecuta legalflow setup --resume.

Alternativa segura

El CLI y la plantilla pueden quedar instalados, pero el trabajo guiado espera a Codex.

legalflow setup --resume
