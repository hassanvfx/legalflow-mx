Actualizar AI LegalFlow MX

Las actualizaciones deben provenir de releases verificadas.

Pasos

  1. Comprueba la versión instalada.
  2. Descarga el release y checksum correspondientes.
  3. Ejecuta legalflow update y después legalflow verify.

Alternativa segura

Permanece en la versión actual si una verificación falla.

legalflow setup --resume
