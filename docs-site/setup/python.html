Instalar runtime del bootstrap

El bootstrap actual requiere Python 3 para iniciar el CLI.

Pasos

  1. Instala Python 3 desde una fuente confiable.
  2. Confirma con python3 --version.
  3. Repite el instalador.

Alternativa segura

Descarga el bundle standalone de la release cuando esté disponible.

legalflow setup --resume
