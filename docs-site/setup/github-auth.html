Autenticar GitHub

La autenticación permite crear un remoto privado; AI LegalFlow MX nunca recibe secretos.

Pasos

  1. Ejecuta gh auth login.
  2. Completa navegador, passkey o 2FA directamente con GitHub.
  3. Vuelve y ejecuta legalflow setup --resume.

Alternativa segura

Continúa local-only; podrás habilitar sincronización privada después.

legalflow setup --resume
