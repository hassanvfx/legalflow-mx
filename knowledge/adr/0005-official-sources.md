# ADR 0005: Fuentes official-first y copias fijadas

Estado: aceptado

Las fuentes mexicanas se identifican primero en dominios oficiales. Una copia
fijada conserva URL, huella y fecha de consulta. Una fuente no oficial puede
orientar investigación, pero no se marca como verificada por ello.
