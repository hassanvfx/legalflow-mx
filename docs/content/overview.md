# AI LegalFlow MX

AI LegalFlow MX ayuda a operar matters jurídicos como objetos y evidencia
versionados. Automatiza el estado técnico; las decisiones jurídicas, los
plazos críticos, los permisos externos y la autenticación siempre requieren
confirmación humana.

## Inicio seguro

```bash
curl -fsSL https://raw.githubusercontent.com/hassanvfx/legalflow-mx/main/install.sh | bash
```

Si algo falta, el asistente imprime pasos, una alternativa segura y el enlace
correspondiente de esta guía. Nunca pegues secretos o códigos de autenticación
en un chat o terminal que no sea el flujo oficial de GitHub.
