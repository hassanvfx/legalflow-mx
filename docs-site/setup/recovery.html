Recuperar un matter

La recuperación verifica originales y reconstruye vistas locales sin reescribir historia.

Pasos

  1. Conserva la carpeta del matter intacta y ejecuta legalflow recover /ruta/al/matter.
  2. En un equipo nuevo, usa legalflow recover --repository propietario/repositorio --destination /carpeta/nueva --confirm; sólo clona si GitHub prueba que el repositorio es privado.
  3. Si se bloquea, conserva el resultado de verify y revisa el archivo señalado antes de sincronizar.

Alternativa segura

Crea un bundle de soporte redactado; no compartas el repo completo por defecto.

legalflow setup --resume
